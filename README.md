# 월말 정산 체크룸

더로이그룹 월말 정산 업무를 자동화하기 위한 **내부용 웹앱**입니다.
이 앱은 "정산 입력 앱"이 아니라 **"자동 분류 검토함"** 입니다.
엑셀 노동을 웹 화면 노동으로 옮기지 않고, 토스 앱처럼 **앱이 기준을 먼저 적용하고
사용자는 예외만 확인·승인**하도록 설계했습니다.

## 핵심 흐름

1. 기존 엑셀 파일 또는 텍스트 메모를 업로드합니다.
2. 앱이 파일명·시트명·컬럼명·항목명·메모를 읽어 **정산 항목 후보**를 자동 생성합니다.
3. 각 항목을 비용유형 / 증빙방식 / 원천세 대상 / 월말 지급 대상 / 대량이체 포함 여부로
   **신뢰도와 함께 자동 분류**합니다.
4. 사용자는 **확인 필요 항목만** 검토하고, 신뢰도 높은 항목은 **일괄 승인**합니다.
5. 승인된 항목을 기준으로 **정산원장**이 만들어지고, 목적별 출력물이 파생됩니다.
6. **신한은행 대량이체 파일**을 포함한 엑셀 출력물을 다운로드하고, **팀 보고 메시지**까지 생성합니다.

> 모든 출력물은 **정산원장 하나**에서 파생됩니다. 사용자가 여러 파일을 각각 수정하지 않습니다.

## 출력물

| 출력물 | 설명 |
| --- | --- |
| 정산원장 엑셀 | 모든 출력물의 기준 데이터 |
| 프로젝트비 관리자료 엑셀 | 프로젝트비 반영 항목 |
| 수당명세서용 자료 엑셀 | 개인 지급 항목 |
| 원천세 신고자료 엑셀 | 세무법인 제출용 (세전/원천세/주민세/실지급액 포함) |
| 월말 지급 예정 목록 엑셀 | 이번 달 실제 지급 대상 |
| 신한은행 대량이체 파일 엑셀 | 실제 이체 대상만 · 실지급액 기준 |
| 월말 정산 검수 리포트 엑셀 | 마감 조건 점검 결과 |
| 팀 보고 메시지 | 마감 완료 보고 문구 (복사) |

### 중요한 역할 분리

- **원천세 신고자료**는 세무법인에 넘기는 자료로만 사용합니다.
  세금계산서 발행 업체 비용 · 신용카드 지출 · 지급완료 단순 지출은 여기에 넣지 않습니다.
- **월말에 실제 지급할 항목**은 별도의 "월말 지급 예정 목록"과 "신한은행 대량이체 파일"로 생성합니다.

## 사업소득 세금 자동 계산

사업소득 신고 대상 항목은 사용자가 원천세/주민세를 직접 입력하지 않습니다.

- 원천세 = 세전 지급액 × 3%
- 주민세 = 원천세 × 10%
- 실지급액 = 세전 지급액 − 원천세 − 주민세 (총 공제율 3.3%)

예) 세전 1,000,000원 → 원천세 30,000 / 주민세 3,000 / 실지급액 967,000원

원천세·주민세 필드는 기본 잠금이며, **수동 수정 시 사유 입력이 필수**입니다.
대량이체 파일에는 세전이 아니라 **실지급액**이 들어갑니다.

## 실행 방법

```bash
npm install
npm run dev        # http://localhost:3000
```

프로덕션(정적) 빌드:

```bash
npm run build      # out/ 폴더에 정적 사이트가 생성됩니다 (GitHub Pages 등에 배포 가능)
```

> `next.config.js`에서 `output: "export"`를 사용해 **서버 없이** 브라우저에서만 동작합니다.
> 파일 파싱·분류·엑셀 생성 모두 브라우저에서 처리하며, 별도 DB나 서버 저장은 없습니다.

## 테스트 방법

```bash
npm run test       # 세금 계산 / 자동 분류 규칙 / 대량이체 출력 단위 테스트
```

테스트 범위:
- `src/lib/taxCalc.test.ts` — 3.3% 원천세·주민세·실지급액 계산
- `src/lib/classificationRules.test.ts` — 9가지 자동 기본값 규칙
- `src/lib/exporters.test.ts` — 신한은행 대량이체 컬럼 순서/금액, 파일명 월 인식

## 샘플 데이터 사용법

업로드 없이 바로 분류·다운로드를 테스트할 수 있습니다.

1. 앱 첫 화면에서 **"샘플 데이터로 해보기"** 버튼을 누릅니다. (4건: 강사비·세금계산서·신용카드·계좌누락 용역비)
2. 검토함에서 확인 필요 항목을 처리하거나 일괄 승인합니다.
3. **출력물 다운로드**에서 신한은행 대량이체 파일 등을 내려받습니다.
4. 내려받은 `.xlsx`를 다시 열어 컬럼 순서/값이 유지되는지 확인합니다.

## 코드 구조

```
src/
  app/                  # Next.js App Router 화면 (UI)
  components/           # 카드형 검토 UI, 모달, 패널 등 컴포넌트
  store/                # zustand 전역 상태 (정산원장 + 검토 액션)
  lib/
    types.ts            # 정산원장 도메인 타입 / 비용유형 / 증빙방식
    classificationRules.ts  # ★ 자동 분류 규칙 (나중에 쉽게 수정 가능)
    taxCalc.ts          # ★ 사업소득 세금 자동 계산 (순수 함수)
    selectors.ts        # 정산원장 → 목적별 항목 선택
    exporters.ts        # SheetJS 엑셀 생성/다운로드
    parseFiles.ts       # 브라우저 파일 파싱 + 파일명 월 인식
    closing.ts          # 마감 체크리스트 / 마감 조건 / 팀 보고 메시지
    bankCodes.ts        # 은행명 → 은행코드 변환
    masters.ts          # 지급대상자 마스터 / 약칭 사전 / 이전 달 항목 (localStorage)
    sampleData.ts       # 샘플 3건+
```

> **검수 로직과 컴포넌트는 분리**되어 있습니다.
> 자동 분류 기준을 바꾸려면 `src/lib/classificationRules.ts`만 수정하면 됩니다.

## 기술 스택

- Next.js 14 (App Router, 정적 export) · TypeScript
- SheetJS(`xlsx`) — 브라우저 파일 파싱 및 엑셀 생성
- zustand — 전역 상태
- Tailwind CSS — 토스 스타일 UI
- Vitest — 단위 테스트

## 이번 버전에서 하지 않는 것

로그인, 실제 은행 이체 실행, 세무신고 자동 제출, 카드사/전자세금계산서 API 연동,
복잡한 권한관리. 디자인 고도화보다 **사용 흐름 개선**을 우선합니다.
